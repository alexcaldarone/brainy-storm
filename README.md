# {Tech: Europe} Agentic AI Hack

Every folder is its own microservice (python server / react frontend).

![Architecture Diagram](public/diagram.png)

### Running locally

Run each command in its own terminal, in this order:

   ```bash
   cd backend/transcriber && uv run python main.py
   ```
   ```bash
   cd backend/engine && uv run python main.py
   ```
